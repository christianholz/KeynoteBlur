# KeynoteBlur

KeynoteBlur quickly creates blurred background slides for Apple Keynote.

## Features

- Paste slides from clipboard or image URLs
- Preview blurred image
- Copy JPEG inside Keynote metadata to clipboard for pasting the scaled image into Apple Keynote with full-slide dimensions
- Optional: KeynoteBlur can mask background images using shapes copied in Keynote

## Shortcuts

| shortcut           | effect                                                       |
| :----------------- | ------------------------------------------------------------ |
| `Cmd + V`          | Paste image from clipboard (e.g., copied Keynote slide, image from browser) |
| `trackpad swipes`  | adjust blur amount (or use slider)                           |
| `Cmd + C`          | Copy blurred image to clipboard                              |
| `Cmd + Option + C` | Copy blurred image to clipboard masked by Keynote shapes in clipboard |
